# Lista de Atividades 03 — Revisão de POO (Kotlin & Java)

Este repositório contém a resolução dos exercícios práticos da Aula 03 da disciplina de **Desenvolvimento Mobile**. O objetivo da lista é consolidar os conceitos fundamentais de Programação Orientada a Objetos (POO) — como classes, atributos, métodos, herança e encapsulamento — alternando e traduzindo estruturas entre **Kotlin** e **Java**.

---

## Tecnologias e Conceitos Utilizados

* **Linguagens:** Kotlin e Java (JDK 17+)
* **Conceitos de POO:**
  * Instanciação de objetos e construtores
  * Métodos de classe e retornos
  * Herança e polimorfismo (`open`/`override` em Kotlin vs. `extends`/@`Override` em Java)
  * Modificadores de acesso e encapsulamento (`protected set`, `private`)
